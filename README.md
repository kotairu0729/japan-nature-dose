# PEI 自然体験の記録

日常的な自然体験を **PEI（Personalised Ecology Index）** で記録・可視化し、
関連する研究知見とあわせて振り返るための Web アプリケーション。

日常的な自然体験がもたらす恩恵は一般に過小評価されている。このアプリは
個人の自然体験を継続的に記録・可視化し、その体験に紐づく科学的知見を
提示することで、「自然は贅沢品ではなく必需品である」という認識の転換を
促すことを目的とする。単なる活動ログではない。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # ロジックとデータのテスト（136件）
npm run build      # 型チェック + 本番ビルド
npm run preview    # ビルド結果の確認
```

Vite + React + TypeScript。グラフは recharts。データは localStorage に保存し、
サーバーには送信しない。

## 指標について

PEI は 0〜1 の標準化スコアで、以下 4 軸の**非加重の単純平均**として算出する。

| 軸 | 内容 | 正規化 |
|---|---|---|
| frequency | 自由時間に自然空間で過ごした頻度（0〜7） | ÷7 |
| duration | 一回あたりの最長滞在時間（1〜7） | ÷7 |
| diversity | 訪れた屋外空間の種類数（0〜10） | ÷10 |
| intensity | 昆虫・景観・鳥・植物への注意（各0〜4） | 各÷4 の平均 |

```
PEI = (frequency + duration + diversity + intensity) / 4
```

論文では非加重版が正式採用されている。加重版との相関が R² = 0.78 と高く、
加重によって識別力が向上する証拠が得られなかったため。実装もこれに従う。

出典：Poznansky, F. et al. (2026). *The Personalised Ecology Index: A novel
measure of an individual's direct sensory interactions with nature.*
People and Nature, 8, 2881–2897. DOI: [10.1002/pan3.70389](https://doi.org/10.1002/pan3.70389)

## 構成

3 層（データ / 純ロジック / UI）を一方向依存にしている。`lib/` は React を
一切 import しないため、算出ロジックの正しさを UI と独立に検証できる。

```
src/
├── types/pei.ts          型定義のみ。他に依存しない最下層
├── data/                 「知識」レイヤー：純データ、UI から完全分離
│   ├── scale.ts            4軸の設問文・選択肢・配点（論文準拠）
│   ├── evidence.ts         科学的知見 27件（→ 下記）
│   ├── benchmarks.ts       英国の集団平均と、適用限界の注記
│   ├── suggestions.ts      低コストな行動提案 20件
│   └── limitations.ts      論文が認める指標の限界 6項目
├── lib/                  「ロジック」レイヤー：純関数のみ、React 非依存
│   ├── pei.ts              正規化・PEI算出・記録の検証
│   ├── series.ts           週次/月次集計、12ヶ月俯瞰、直近と平均の比較
│   ├── evidenceSelect.ts   スコアに応じた知見の選択
│   ├── suggest.ts          最低軸の特定と提案の選択
│   └── storage.ts          localStorage 永続化と JSON 入出力
├── state/RecordsContext.tsx  useReducer + Context
├── components/           表示部品（charts/ にグラフ）
└── pages/                ホーム・記録・推移・知見・設定
```

### 状態管理

ドメイン状態は「記録の配列」ただ一つ。PEI スコア、平均、最低軸、提示する知見は
すべてそこからの**派生値**として `useMemo` で計算し、状態としては持たない
（二重管理による不整合を防ぐため）。永続化は reducer の外側の effect で
「state が変わったら書く」一方向に限定している。

読み込み時に壊れた記録があっても全体を捨てず、妥当な記録だけを採用して
除外件数をユーザーに開示する。

## 科学的知見データ

`src/data/evidence.ts` に 7 領域 27 件。**実在が確認できる文献のみ**を収録し、
書誌情報や DOI に確信が持てない候補はエントリ化せず、ファイル末尾に
コメントでプレースホルダとして残している。

| 領域 | 件数 |
|---|---|
| 精神的健康 / 認知機能 / 身体的健康 / 注意を向けること / 用量反応関係 / 緑地アクセスの不平等 | 各4件 |
| 経験の絶滅 | 3件 |

### 追記の手順

1. `EVIDENCE` 配列に追加する（`id` は一意、`domain` は 7 種のいずれか）。
2. `npx vitest run src/data/evidence.test.ts` を実行する。

`evidence.test.ts` が以下を自動で検査する。知見を足すときに品質が落ちないための仕組み。

- ID・DOI の重複、DOI の形式、著者・雑誌名・出版年の妥当性
- `caveat` の欠落と、研究デザイン・対象集団への言及の有無
- 横断研究を扱う知見が因果の限界に触れているか
- 診断・予測を思わせる断定表現の混入（「治ります」「予防できます」等）
- 相関を因果と言い換える表現（「効果が証明された」「確実に」等）
- 読者個人に効果を約束する表現（本文に「あなた」「PEI」が現れないこと）

## 設計上の判断

### 指標の限界を開示する

設定画面に常設し、論文自身が認める限界を開示している。PEI が捉えるのは
自由時間の意図的な体験のみで通勤中の偶発的接触は含まないこと、
多様性軸の分類は英国のものを日本向けに読み替えた暫定的なものであること、
スコアの「良い・悪い」を断定すべきでないこと、想起によって数値が動くこと。

これに加えて、実装で気づいた点も開示している。滞在時間の選択肢には 0 点が
存在せず、最短の「30分以下」でも 1/7 ≒ 0.14 が加算されるため、
ひと月まったく出かけなくても PEI がゼロにはならない。

### 置かなかったもの

- **ランキング・スコアの競争**：自然体験の商品化・競争化はプロダクトの目的に反する
- **連続記録日数などのストリーク**：義務感を生み、記録が途切れたときに責める構造になる
- **道具主義的なメッセージ一辺倒**：「健康になるために自然に行こう」は
  自然体験それ自体の価値を毀損する。研究知見は日常の体験を過小評価しないための
  材料として置き、自然を手段に位置づけない

行動提案はすべて無料または数百円程度で、通勤・買い物など既存の移動の中で
実行できるものに限っている。自然体験を特別な余暇活動ではなく日常の一部として
捉え直すため。

### グラフの配色

配色は検証器にかけて選んでいる。当初の緑系4色は彩度が低く、隣接ペアの
色覚多様性下での色差が ΔE 3.0 と識別できなかったため、検証済みの
カテゴリカル配色に差し替えた（隣接 CVD ΔE 9.1 / 通常視 22.9、暗色面でも 8.4 / 19.8）。

4 軸を 1 枚のグラフに重ねると全ペア基準を満たせないため、軸ごとに分けた
スモールマルチプルとし、系列の識別は見出しの文字が担う構成にしている。
明色面でコントラストが 3:1 未満になる 2 色があるため、値は必ず数字でも併記し、
表形式の代替表示も用意している。
